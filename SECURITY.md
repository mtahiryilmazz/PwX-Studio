# Güvenlik Politikası (Security Policy)

## Desteklenen Sürümler

PwX Studio aktif olarak en son kararlı sürümü için güvenlik güncellemeleri alır:

| Sürüm | Destek Durumu |
| :--- | :--- |
| **1.5.x** | ✅ Aktif Olarak Destekleniyor |
| < 1.5.0 | ❌ Desteklenmiyor (Eski PS2EXE motoru) |

## Güvenlik Açığı Bildirimi

PwX Studio'da veya PwX Build Engine'de bir güvenlik açığı tespit ettiyseniz:
Lütfen herkese açık bir Issue açmak yerine doğrudan **thrylmz@live.cn** e-posta adresine bildiriniz veya GitHub Security Advisory özelliği üzerinden özel bildirim oluşturunuz.

Bildiriminiz en geç 48 saat içerisinde değerlendirilecektir.
